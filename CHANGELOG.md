# Changelog

All notable changes to this community-maintained Agent Skill are documented here.

## [2.0.0] - 2026-11-09

- Made the skill host-neutral, designed around `Host Agent` rather than Codex-specific tool APIs.
- Added installation support for Codex, Claude Code and DeepSeek Harness (DSH), including portable project-level installs.
- Added LOCAL, KHA-NATIVE, and KHA-HOST routing with delegation, permission, and verification guards.
- Added example Agent configurations, CLI cookbook, official source index, and recovery guidance.
- Added a comprehensive bilingual-introduction README, security-focused `.gitignore`, and local validation scripts.

## Versioning notes

Version metadata lives in `SKILL.md` (`metadata.version`). This release has been statically validated but has not been tested against any particular user's paid KHA account.
